# Learning route policy

The route is an explainable ordering of the four available development lessons, not a full curriculum plan or exam-readiness score. It reads only the current account's profile, attempts, and saved positions. No new database tables or migration are needed.

Priority order:

1. Completed learning sequences with a due, unfinished delayed review. Oldest due review comes first.
2. Prerequisite checks with an incorrect attempt and no successful answer yet. Most recently active comes first. The action returns to the diagnostic step.
3. Started, incomplete sequences, most recent first. Their existing learning position is preserved.
4. New lessons at or below the selected grade. Subject focus, then ascending grade, then a suitable interest connection break ties.
5. Unstarted later-grade previews, explicitly labelled. These are not prerequisites the student is expected to have completed.
6. Completed sequences awaiting recall, then sequences with a successful delayed check. These remain accessible without being presented as new evidence.

JEE focuses new suggestions on mathematics, physics, and chemistry; NEET on biology, physics, and chemistry. CBSE foundations and programme-dependent BITSAT, CUET, state exam goals retain all four subjects. This does not infer the subject combination required for a particular programme. All lessons remain accessible, including optional subjects.

An unresolved diagnostic brings back one short foundation explanation. Examples use different values from the question. Opening an explanation before a first attempt records support server-side; an incorrect answer already makes future attempts retries. A successful retry removes the unresolved-check recommendation but does not erase the assistance record. No fresh mastery evidence is claimed from repeating the same question.

The action that opens a recommended step saves that position before navigating, so both the lesson and text coach see the same stage. Delayed-answer submission still independently enforces the due date. A link to the review step cannot unlock it early.

Limitations: the single diagnostic per lesson cannot assess every listed prerequisite; grade placement is draft and not a verified 2027 syllabus mapping; authored foundation notes require educator review. A larger prerequisite graph, unseen follow-up questions, mixed revision, multi-exam/programme selection, and immutable content releases remain separate work.
